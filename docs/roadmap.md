# Roadmap

## Phase 0: Public Prototype

- Publish static high-fidelity UI.
- Document synthetic data provenance.
- Provide screenshots and architecture summary.
- Establish open-source license and public repository.

## Phase 1: Technical Validation

- Connect the prototype to public or synthetic benchmark datasets.
- Create reproducible model-validation notebooks.
- Add automated checks for code quality, dependency integrity, and secret leakage.
- Package the Community Edition deployment path.

## Phase 2: Pilot Readiness

- Prepare pilot data dictionary and data-sharing checklist.
- Draft district onboarding and training materials.
- Add privacy review templates.
- Define success metrics for attendance, course-failure, engagement, and counselor workflow efficiency.

## Phase 3: Early Pilots

- Conduct limited pilots with willing education partners.
- Use written agreements and approved data handling.
- Publish only aggregated, non-identifying findings.
- Refine model explainability and educator workflows.

## Phase 4: Broader Release

- Expand open-source package.
- Complete SOC 2 readiness and third-party security testing.
- Add additional state privacy modules.
- Build implementation partner network.
