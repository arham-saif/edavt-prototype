# Data Provenance

All data in this repository is synthetic demonstration data.

## Synthetic Data Categories

- district name and school names;
- user names and roles;
- student IDs and student initials;
- attendance, GPA, engagement, risk, and intervention metrics;
- connector sync status and record counts;
- audit log events;
- compliance and security control rows.

## What Is Not Included

This repository does not include:

- real student records;
- FERPA-protected education records;
- real personnel records;
- district credentials;
- API keys or secrets;
- production logs;
- private data-sharing agreements.

## Why Synthetic Data Is Used

Synthetic data allows the prototype to demonstrate workflow, visual design, role scope, and privacy controls without exposing protected records. Any future pilot would require written agreements, privacy review, and de-identification rules before real data is processed.
